# KenaKata

এই ডিরেক্টরি কাল্পনিক পণ্যের ক্যানন। অধ্যায় লেখার সময় এখানে তাকাতে হয়। গল্পের সুবিধার জন্য নতুন স্থায়ী তথ্য বানিয়ে ফেলা যাবে না। নতুন তথ্য লাগলে সংশ্লিষ্ট ফাইল, টাইমলাইন, এবং প্রভাবিত অধ্যায় একসঙ্গে বদলায়।

| [characters.md](characters.md) | আরিফ, নীরা, রাফি |

একই KenaKata নিয়ে Trust Stack অথেন্টিকেশন ও অথরাইজেশন শেখায়। এই রিপোজিটরি সেই পাঠের নেটওয়ার্ক সঙ্গী। অ্যাপ্লিকেশন নিরাপত্তার অধ্যায় এখানে নকল করা হয় না।
