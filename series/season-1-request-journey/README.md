# সিজন ১ — একটি Request-এর যাত্রা

অধ্যায় ১–৬। লক্ষ্য: ক্রেতার একটি পাতা খোলাকে এমন প্রশ্নে ভাঙা, যেগুলো আলাদা করে পরীক্ষা করা যায়।

## আগে কী লাগবে

প্রোগ্রামিং ও HTTP চেনা। নেটওয়ার্কের কোর্স নয়। KenaKata এখন একটি অ্যাপ্লিকেশন সার্ভার। [টাইমলাইন](../../product/timeline.md)।

## শেষে কী ব্যাখ্যা করতে পারবে

- নাম, রাউটিং, লিংক, TCP, TLS, ও HTTP একই সাফল্য নয়।
- OSI স্তর যন্ত্রের তালিকা নয়।
- MAC, IP, পোর্ট, ও সকেট আলাদা প্রশ্ন।
- HTTP স্ট্যাটাস কানেকশন উঠেছে কি না, সেই প্রশ্ন থেকে আলাদা।
